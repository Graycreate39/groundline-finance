# Scenario and version semantics

A model version is an immutable analytical checkpoint. Scenarios are named patches from that baseline, preserving stable driver identifiers rather than copied tables. Base, Downside, and Upside intentionally change different operating drivers; they are not blanket percentage shocks.

Change attribution applies scenario patches sequentially and measures each marginal change in the selected output. Because nonlinear effects depend on order, Groundline names the method and carries remaining interaction as residual. Decisions link to the model version and relevant scenarios so later changes do not rewrite the original basis.
